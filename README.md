# Rock-Paper-Scissors Game

Welcome to the Rock, Paper, Scissors game! This project is a simple implementation of the classic hand game where players choose between rock, paper, scissors, lizard or spock, and the winner is determined based on the game’s rules.


## Features

• Single-player mode against a computer.

• Randomized computer moves to ensure fairness.

• A user-friendly interface for input and output.


## Usage

1. The player selects one of the five options: rock, paper, scissors, lizard or spock.

2. The computer randomly selects its choice.

3. The game compares the choices using the rules:
  • Rock beats scissors and lizard.
  • Scissors beat paper and lizard.
  • Paper beats rock and spock.
  • lizard beats paper and spock.
  • spock beats rock and scissors.

5. The result (win, lose, or draw) is displayed.


## Installation

1. Clone this repository:
   git clone (link)
   
2. Navigate to the project directory:
   cd rock-paper-scissor
   
3. Ensure you have Python installed.
   (Version 3.6 or higher)

4. Install pygame:
   pip install pygame

5. Run the game:
   python rps.py


## How to Play

1. Press a button of your choice (rock, paper, scissors, lizard or spock).

2. The computer will then randomly make its choice.

3. The results will be shown.

4. Continue playing or quit by following the on-screen instructions.
